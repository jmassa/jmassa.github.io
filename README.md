# José María Massa

Personal academic site, migrated from Google Sites
(`sites.google.com/site/josemariamassa/jose-maria-massa`) to GitHub Pages.

Plain static HTML: each page is a standalone `.html` file sharing `style.css`.
To edit a page, change its HTML directly and push; GitHub Pages republishes automatically.

Preview locally:

```bash
python3 -m http.server 8000
```
